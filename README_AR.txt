مشروع My First App - Java Android

محتويات المشروع:
- MainActivity.java: واجهة التطبيق وسلوك الزر.
- AndroidManifest.xml: تعريف التطبيق والشاشة الرئيسية.
- app/build.gradle: إعدادات بناء وحدة التطبيق.
- build.gradle و settings.gradle: إعدادات Gradle للمشروع.

ملاحظة حول Klencod IDE:
يمكن استيراد المشروع كملف ZIP إذا كان إصدارك يدعم استيراد المشاريع.
لكن المعلومات المتاحة عن Klencod IDE تركز على مشاريع Flutter؛ لذلك لا أستطيع ضمان أن زر Build يدعم مشاريع Android الأصلية المكتوبة بـ Java. الاستيراد والتحرير لا يعنيان بالضرورة إمكانية البناء.

إعدادات المشروع:
- Package: com.example.myfirstapp
- Minimum Android: API 23
- Compile SDK: 35
- اللغة: Java
- لا يحتاج التطبيق إلى صلاحيات أو إنترنت.

إذا لم يقبل Klencod المشروع أو لم يظهر خيار بناء Java/Android، أرسل صورة شاشة الخيارات ورسالة الخطأ لأضبط الهيكل حسب إصدارك.
